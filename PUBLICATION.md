**Публичный сайт:** [lyoshagodx.github.io/quizzle-csv-export-report](https://lyoshagodx.github.io/quizzle-csv-export-report/).

GitHub Pages настроен через REST API на ветку `main`, каталог `/`. API подтвердил статус `built`, HTTP-запрос страницы вернул 200. HTML, два используемых снимка и два CSV-файла дополнительно сопоставлены с локальными файлами: [report-pages-check.json](evidence/report-pages-check.json). Для HTML учтена нормализация CRLF в LF согласно правилам Git; снимки и CSV совпадают побайтово. Визуальная браузерная проверка страницы не заявляется.

Настройка соответствует [официальному описанию GitHub Pages API](https://docs.github.com/en/rest/pages/pages#create-a-github-pages-site). После новых коммитов GitHub может кратковременно показывать состояние очередной сборки; этот протокол фиксирует успешно опубликованный комплект на момент проверки.

Публикация отдельного комплекта выполняется после первоначального цикла разработки; его временные отметки не включаются в интервал до merge PR #9.
