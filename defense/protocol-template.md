# Шаблон протокола публичного выступления

**Не заполнено. Не является подтверждением состоявшегося выступления.**

Материалы для защиты: [сценарий](../speech.md), [страница результатов](../index.html), [отчет](../README.md).

После реального выступления студент может указать:

| Сведения | Фактические данные после выступления |
|---|---|
| Дата, время и площадка | |
| Формат и аудитория | |
| Продолжительность | |
| Показанные материалы и демонстрация | |
| Полученные вопросы | |
| Ответы и замечания преподавателя | |
| Итог и необходимые исправления | |
| Разрешенные к публикации подтверждения | |

Не публиковать имена, изображения участников или запись без необходимого согласия. После заполнения сохранить фактический протокол отдельным файлом; этот шаблон не превращать в вымышленное описание события.
